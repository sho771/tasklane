# Tasklane

タスク一覧とインタラクティブなガントチャートを備えたデスクトップ向けタスク管理ツールです。

## 実装済みの内容

- 左ペインにタスク一覧、右ペインにガントチャートを表示します。
- 左ペイン上部の `Task Add` ボタンからタスクをすばやく追加できます。
- 左右ペインの境界をドラッグして幅を変更できます。
- 左ペインの上部操作エリアは固定され、タスク一覧のみ独立してスクロールします。
- 左側のタスク行と右側のガント行の高さが揃うようにしています。
- タスク検索、ステータス、タグ、期限日で絞り込めます。
- Today / Next / Waiting のフォーカスビューで、次に見るべきタスクを確認できます。
- タグ階層ごとにタスクをグループ表示できます。
- タググループは折りたたみと色変更に対応しています。
- Google AI Studio、OpenAI、Claude、OpenAI互換APIを使い、自然文メモからタスク候補を作成できます。
- 今日の日付はタイムラインヘッダー上で強調表示されます。
- ライトモードとダークモードを切り替えられます。

## タスク操作

- タスク名またはタスク No をクリックすると詳細モーダルを開けます。
- 詳細モーダルでは、タスク名、UID、開始日、期限日、ステータス、進捗率、タグ、依存関係、優先度、メモを編集できます。
- タスクの `UID` は `Task Add` 時に `YYYYMMDDHHmmss` 形式で自動生成されます。
- タスク No と Markdown ファイル名の通し番号は全般設定の `Next Index` から採番されます。
- 詳細モーダルの `Copy` からタスクを複製できます。
- 詳細モーダルのタグはチップとして表示され、入力欄から追加できます。
- 詳細モーダルのタグ候補と依存候補は、候補数が多い場合もリスト内でスクロールできます。
- タググループ行を右クリックすると、そのタグを初期値にしたタスクを追加できます。
- 通常の `Task Add` ではタグなしのタスクを作成します。タグフィルタ中は、そのタグを初期値にします。
- `AI Inbox` から自然文を入力すると、AIがタスク候補に整理します。候補は保存前に編集・選択できます。
- 詳細モーダルの `Googleカレンダーで開く` から、Google Cloud設定なしでGoogleカレンダーの予定作成画面を開けます。
- メモ欄は Markdown のライブプレビューに対応しています。
- モーダルからタスクを削除できます。

## Notes の Markdown 対応

Notes は Markdown ソースを保持したまま編集します。

- カーソルがある行は Markdown ソース表示になります。
- カーソルがない行は表示寄りになり、太字、斜体、打ち消し線、下線、インラインコード、リンク、リスト、チェックリストなどを読みやすく表示します。
- `- [ ]` / `- [x]` のチェックリストは、非カーソル行ではチェックボックスとして表示されます。
- チェックボックスをクリックすると Markdown 本文の `[ ]` / `[x]` が更新されます。
- コードブロックはフェンス記法の言語名に応じてシンタックスハイライトされます。
- 太字、斜体、見出し、リストなどの Markdown ショートカットに対応しています。
- テーブル入力用の Markdown ショートカットに対応しています。
- 現在の日付を `YYYY-MM-DD` 形式で挿入する Markdown ショートカットに対応しています。
- 太字、斜体、打ち消し線、インラインコードは、既に囲まれている箇所でショートカットを使うと装飾を解除できます。
- ショートカット割り当ては全般設定の一覧 UI または `Markdown Shortcuts JSON` で変更できます。

対応している主なコードブロック言語:

- `js` / `javascript`
- `ts` / `typescript`
- `jsx`
- `tsx`
- `css`
- `html`
- `json`
- `bash` / `sh` / `shell` / `zsh`
- `python` / `py`
- `sql`
- `php`
- `ps1` / `powershell` / `pwsh`
- `md` / `markdown`

## 全般設定

左上の `⋮` メニューから `Settings` を開けます。

- `Index Digits`: Markdown ファイル名に付けるタスク No のゼロ埋め桁数です。初期値は `4` です。
- `Next Index`: 次に追加するタスクへ割り当てるタスク No です。タスク追加後に自動で次の番号へ進みます。
- `次やるタスク表示数`: 右ペインの `Today`、`Next`、`Waiting` に表示するタスク数を設定できます。初期値は `6` です。
- `File Name Rule`: Markdown ファイル名のルールです。`{index}`、`{no}`、`{id}`、`{name}`、`{uid}`、`{status}` を使えます。
- `AI`: AIプロバイダー、API Key、モデルID、OpenAI互換エンドポイントを設定できます。APIキーはOSの安全な保存領域に暗号化して保存され、通常設定のJSONには保存しません。
- `Googleカレンダー`: 予定作成画面を開くときの、終日予定、開始時刻、所要時間の既定値を設定できます。
- `Statuses`: タスクに使うステータスの表示名とカラーを編集できます。既定ステータスは削除できません。
- `Markdown Shortcuts`: Markdown 入力ショートカットを一覧から編集できます。
- `Markdown Shortcuts JSON`: Markdown 入力ショートカットの割り当てです。`bold`、`italic`、`heading1`、`checklist`、`table`、`currentDate` などのアクションに CodeMirror 形式のキー名を設定できます。
- `Tags`: 既存タグの色変更、リネーム、タスクからのタグ削除、`#task` 付きノートの取り込みを行えます。
- `Vault Sync Log`: Vault 選択、インポート、自動同期の直近 10 件を確認できます。

## ガントチャート操作

- タスクバーをドラッグすると、開始日と期限日をまとめて移動できます。
- タスクバー左右のハンドルをドラッグすると、開始日または期限日を変更できます。
- ガントチャートの空白部分をダブルクリックすると、その行と日付に合わせてタスクを追加できます。
- 依存関係は矢印付きの線で表示されます。
- 親子関係は点線のガイドで表示されます。
- 進捗率の位置をタスク間でつなぐ稲妻線を表示できます。
- タググループを折りたたむと、配下タスクの開始日と期限日をまとめた集約バーを表示します。
- チャートバー上では、タスク No の左にステータス色のドットを表示します。

## AI Inbox とフォーカスビュー

- `AI Inbox` では、やることを自然文で入力し、設定したAIプロバイダーでタスク候補へ整理します。
- AIが作成した候補は、タスク名、開始日、期限日、ステータス、優先度、タグを確認・編集してから保存できます。
- APIキーとモデルIDは Settings の `AI` セクションで設定します。APIキーはOSの安全な保存領域に保存し、リポジトリや通常設定JSONには含めません。
- 画面右端の `次やるタスク` ペインでは、`Today`、`Next`、`Waiting` を切り替えられます。完了状態、開始日、期限日、依存関係、優先度から自動で並び替えます。
- `次やるタスク表示数` で、各分類に表示する件数を変更できます。

## Googleカレンダー連携

- タスク詳細モーダルの `Googleカレンダーで開く` から、Googleカレンダーの予定作成画面をブラウザで開けます。
- タスク名、期間、メモ、タグが予定作成画面へ入力された状態になります。
- Googleカレンダー側で `保存` すると、Google側の通知設定に従って通知を受け取れます。
- Google Cloud設定やクライアントIDは不要です。
- Google側で予定を変更してもTasklaneには自動反映されません。

## キーボード操作

- `Ctrl+N` / `Cmd+N`: 新規タスクを追加します。
- `Ctrl+F` / `Cmd+F`: タスク検索欄へフォーカスします。
- `Ctrl+Z` / `Cmd+Z`: タスク操作を取り消します。
- `Ctrl+Shift+Z` / `Cmd+Shift+Z`、`Ctrl+Y`: 取り消した操作をやり直します。
- `Esc`: 詳細モーダル、設定モーダル、メニューを閉じます。

## Obsidian Vault 連携

`Task Add` 以外の Vault 操作は、左上の `⋮` メニューにまとめています。

- `Vault`: Obsidian Vault フォルダを選択します。
- Vault 選択時に、Vault 内の Markdown ファイルを読み込んでタスクへ反映します。
- `Vault Off`: 現在の Vault 接続を解除します。
- `Import File`: 選択した 1 つの Markdown ファイルからタスクを取り込みます。
- `Clear Tasks`: すべてのタスクを削除します。
- Vault 選択後は、タスクの追加、削除、修正が Markdown ファイルへデバウンス付きで自動同期されます。
- Vault 内の `#task` 付き Markdown ノート取り込みは、Settings の `Tags` セクションから実行できます。
- Tasklane が管理する Markdown ファイルは、削除やタグ変更に合わせて同期されます。
- Vault 同期ログは画面上では直近 10 件を表示し、Vault 配下の `.log/vault_log.log` に追記保存します。

## Markdown ファイルの保存ルール

- ファイル名は初期状態で `<4桁タスクNo>_<タスク名>.md` 形式です。
- 全般設定の `File Name Rule` でファイル名ルールを変更できます。
- タグをフォルダ階層として扱います。
- たとえば `#task/core` が付いた `設計確認` というタスク No 1 は、`task/core/0001_設計確認.md` として保存されます。
- タグがないタスクは `NoTag/` 配下に保存されます。
- Windows でファイル名に使えない文字は保存時に除去されます。

## 対応している Markdown 取り込み形式

- Tasklane が出力した frontmatter 付き Markdown ノート
- Obsidian などで使うチェックリスト形式のタスク行

例:

```md
- [ ] タスク名 #task 2026-04-30
```

Markdown 読み込み時は UTF-8 に加えて、日本語環境で使われる Shift_JIS / EUC-JP / ISO-2022-JP もフォールバックとして試します。
